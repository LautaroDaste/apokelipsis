Configurar acceso

Tu llave de GitHub se guarda cifrada en este navegador con una contraseña que solo vos sabés.

¿Cómo consigo el token?
  1. Entrá a github.com/settings/personal-access-tokens/new.
  2. Repository access → Only select repositories → este repositorio.
  3. Permissions → Contents → Read and write.
  4. Generá el token, copialo y pegalo acá.
