Iniciar sesión

Solo quien tenga la llave (token) del repositorio puede editar la lista. Se guarda únicamente en este navegador.

¿Cómo consigo el token?
  1. Entrá a github.com/settings/personal-access-tokens/new.
  2. En Repository access elegí Only select repositories y seleccioná este repositorio.
  3. En Permissions → Repository permissions → Contents elegí Read and write.
  4. Generá el token, copialo y pegalo acá.
